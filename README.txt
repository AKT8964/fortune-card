GitHub Pages 部署方式

1. 在 GitHub 建立一個新的 Repository，例如：fortune-card
2. 將本資料夾內的所有檔案上傳到 Repository 根目錄。
3. 確認 index.html、card-1.png～card-9.png 都在根目錄。
4. GitHub Repository → Settings → Pages
5. Build and deployment → Source 選「Deploy from a branch」
6. Branch 選 main，資料夾選 / (root)，按 Save。
7. 等待 GitHub Pages 部署完成後，按 Visit site。

專案型網站網址通常會是：
https://你的GitHub帳號.github.io/fortune-card/

注意：GitHub Pages 是公開網站，請不要放入密碼、個人資料或其他敏感資訊。
